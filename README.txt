SAVANNA BREW CAFE WEBSITE
=========================

HOW TO RUN
1. Extract the savanna-brew folder from the ZIP file.
2. Open the folder.
3. Double-click index.html (or right-click and open it with Chrome, Edge or Firefox).
4. Use the navigation links to open the other four pages.

PROJECT FILES
- index.html       Home page
- about.html       About Us page
- menu.html        Menu with three price tables
- gallery.html     Eight-image responsive gallery
- contact.html     Contact details, opening hours and reservation form
- css/style.css    Shared external stylesheet
- images/          Local SVG artwork used by the pages

IMPORTANT
This is a front-end HTML and CSS assignment. The reservation form displays required-field
validation in the browser, but it does not send or save a booking. A real booking system
needs a server-side form handler or a form service.

The café details and contact information are the fictional details supplied in the assignment.
The illustrations are original SVG placeholders so images display locally without needing
separate downloads. You can replace them with your own photographs, keeping the filenames
or updating the image paths in the HTML.

Before submitting, test all five pages and validate the HTML and CSS using the W3C validators.

# Savanna Brew website resources

This folder contains image assets cropped from the web-site screenshots.
Therefore, the photos and logo here are crops from those screenshots; their resolution and edges may reflect the screenshot. 
Text, navigation, cards, forms, social icons and map controls should be recreated with HTML/CSS (and suitable icon assets/library), rather than using the whole screenshot as a page background. For the map, use a live map embed/link rather than the screenshot crop.
## Folder structure
- `brand/` — logo/wordmark crop
- `banners/` — page hero/banner crops for Contact, Gallery, Menu and About
- `gallery/` — eight menu/product gallery photographs
- `about/` — founder portrait
- `reference/` — original screenshots for layout and content reference

## Suggested HTML/CSS usage
Use relative paths such as:
- `resources/brand/savanna-brew-logo.png`
- `resources/banners/menu-coffee-banner.jpg`
- `resources/gallery/latte.jpg`
- `resources/about/founder-portrait.jpg`
